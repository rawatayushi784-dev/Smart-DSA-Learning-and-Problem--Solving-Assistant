# 💻 Smart DSA Learning and Problem Solving Assistant

## 📌 Introduction
Smart DSA Learning and Problem Solving Assistant is a C++-based project that helps students learn and practice Data Structures and Algorithms. It provides an interactive platform to perform data structure operations and solve coding problems.

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Data Structures and Algorithms (DSA)
- **Data Structures:** Linked Lists, Stacks and Queues
- **Tools:** VS Code
- **Other Concepts:** Pointers, File Handling and Modular Programming

## ✨ Key Features
1. **Linked List Operations:** Supports insertion, deletion and traversal.
2. **Stack and Queue Operations:** Implements fundamental stack and queue operations.
3. **DSA Practice:** Provides practice questions and coding problems.
4. **Performance Tracking:** Maintains student performance and learning progress.

## ⚙️ Working Process
1. The user starts the application and accesses the main menu.
2. The user selects a data structure or learning activity.
3. The application performs the selected linked list, stack or queue operation.
4. Users practice DSA questions and coding problems.
5. Student performance and progress information are managed by the application.
6. File handling is used to save and retrieve relevant progress data.
