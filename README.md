# Smart DSA Learning and Problem-Solving Assistant

A C++-based project designed to help students practice Data Structures and Algorithms (DSA), solve coding problems, track performance, and improve problem-solving skills.

## Features
- DSA learning modules
- Coding practice problems
- Performance tracking
- Problem recommendations
- File-based progress management

## Technologies Used
- C++
- Data Structures and Algorithms
- File Handling
- Object-Oriented Programming

## How to Run

Compile the project using:

```bash
clang++ -std=c++17 main.cpp Student.cpp Learning.cpp Practice.cpp problembank.cpp performance.cpp linearDS.cpp FileManager.cpp recommendation.cpp -o assistant
```

Run the program:

```bash
./assistant
```

## Purpose
To make learning DSA easier through structured practice, progress tracking, and problem-solving activities.
